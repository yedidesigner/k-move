# 1단계: 화면 구조 · 확정 일정 · Firebase 기본 연결

## 목표
K-Move 미국 디자인 실무 취업 연수과정 LMS의 반응형 기본 화면, 24회차 확정 일정, Firebase(Auth Google 로그인 + Firestore) 연결 모듈, 승인/역할별 경로, 기본 Firestore 규칙과 연결 안내 문서를 구현한다. Lovable Cloud(Supabase)는 사용하지 않는다.

## 화면 구성
- 공통 레이아웃: 데스크톱 좌측 사이드바(사이트 이름 + 강의명 구분 표시), 모바일 상단 헤더 + 하단 주요 메뉴 탭. 긴 사이트 이름은 줄바꿈 허용.
- `/login`: Google 로그인 버튼. Firebase 미설정 시 학생에게는 "준비 중" 안내.
- `/pending`: 로그인했으나 수강 미승인 사용자 전용 승인 대기 화면.
- 학생 메뉴 (승인 사용자만):
  - 홈: 오늘/다음 수업(Asia/Seoul 기준), 날짜·시간 10:00~18:30, 공지(빈 상태), 자료·과제 바로가기
  - 전체 수업: 24회차 카드, 월별 필터, 회차 상세(제목 "수업 주제 준비 중", 세부 내용 비공개 표시)
  - 자료실 / 과제 / 내 출석: 데이터 연결 전 빈 상태 + 준비 중 사유 표시(가짜 데이터 없음). 프롬프트 복사 버튼 컴포넌트는 준비.
  - 내 포트폴리오: 목표 직무, 소개문(한/영), 대표 프로젝트, 웹 주소, PDF 링크, 진행 상태 입력 폼 → Firestore 저장(로딩·저장 중·오류·저장 완료 상태).
  - 실습 도구: Gemini, Google AI Studio 새 탭 링크.
- 관리자 메뉴 `/admin` (강사 역할만): Firebase 연결 상태 진단, 필요한 설정값 목록, 승인된 도메인 안내, 수강 승인 대기자 목록(Firestore 실제 데이터, 승인/거절은 규칙으로 강사만 허용).

## 데이터·권한 설계 (Firestore)
- `users/{uid}`: 로그인 시 본인 프로필 생성(role 필드는 클라이언트가 쓸 수 없음).
- `roles/{uid}`: `{ role: "instructor" }` — Firebase Console에서만 생성.
- `enrollments/{courseId}_{uid}`: `{ status: "pending" | "approved" | "rejected" }` — 본인은 pending 신청만, 승인은 강사만.
- `sessions/{sessionId}`: 공개 일정 필드만, `sessions/{id}/private/*` 세부 내용은 공개 플래그 + 승인 사용자만.
- `portfolios/{uid}`, `submissions`, `feedback`: 본인·강사만 접근.
- `firestore.rules` 파일로 위 규칙 작성, 화면 숨김과 별개로 규칙에서 검사.

## 디자인
- 흰색·밝은 회색 배경, 진한 네이비 텍스트, 블루 포인트(oklch 토큰). Pretendard 웹폰트.
- 상태 배지는 색 + 텍스트, 명확한 포커스 링, 최소 44px 버튼.

## 기술 상세
- `firebase` 패키지 설치, `src/lib/firebase.ts`에서 `VITE_FIREBASE_*` 값으로 지연 초기화(브라우저 전용, SSR 안전). 값이 없으면 `configured=false` 반환.
- 웹 설정값(apiKey, authDomain, projectId, appId 등)은 공개 값이므로 VITE_ 환경변수로 사용. 서비스 계정 키·OAuth 토큰은 코드에 넣지 않음.
- `AuthProvider`: onAuthStateChanged → roles/enrollments 조회 → 상태 `loading | signedOut | pending | student | instructor | notConfigured | error`.
- 라우트: `__root` 레이아웃, `login`, `pending`, `_app` 보호 레이아웃(home, sessions, sessions.$id, materials, assignments, portfolio, attendance, tools), `admin`.
- `src/data/schedule.ts`: 24회차 확정 일정, 요일은 날짜에서 Asia/Seoul 기준 계산. 총 교육시간·출석률 표시 없음.
- 문서: `docs/firebase-setup.md`(설정값 위치, 승인된 도메인 등록: Lovable 미리보기 도메인 `id-preview--1514fd04-...lovable.app`과 배포 도메인, 강사 UID 지정 방법, 규칙 배포 방법), `AGENTS.md`에 기술 결정 기록.
- 일정 요일 계산 테스트 추가.
- 각 페이지 head() 메타데이터 설정.

## 완료 보고 형식
구현한 기능 / 실제 연결·검증한 기능 / 필요한 설정값 / 다음 단계로 구분. Firebase 설정값과 강사 UID가 없으면 실제 로그인·권한 검증은 미완료로 보고.
