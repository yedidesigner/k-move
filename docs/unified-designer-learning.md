# 디자이너를 위한 통합 용어 학습

## 구성 기준

대상은 디자이너 하나로 통합한다. 경력별 경로와 수준 분류를 제거하고, 용어의 정의부터 실무 판단까지 같은 학습 흐름에서 읽는다. 기존 239개 영어 표제어·한국어 정의·실무 해설, 예시 195개와 실습 포함 44개, CTA·햄버거 메뉴·캐러셀 데모와 흰색 설명면을 보존한다.

- 학습 진입점은 `/glossary`다. 별도 자료실 메뉴를 제거하고 모바일 하단 탐색도 용어집으로 연결한다. `/materials`는 `/glossary`로 replace 리디렉션한다.
- 용어 학습은 기본으로 펼친 핵심 구조, 실제 맥락의 예시, 필요한 경우 직접 해보기 순서다. 정적 예시는 실제 조작과 구분한다.
- 용어집 하단의 `주제별로 이어 배우기`는 기본으로 닫는다. 안에는 20개 가이드의 검색과 주제 필터만 둔다.
- 용어 안의 `이 개념을 더 이해하기`는 가이드의 관련 용어 ID 또는 `visualTermId`와 정확히 일치할 때만 연결하고, 같은 화면에서 설명을 펼친다. 제목 유사도나 주제 일치만으로 가이드를 추천하지 않는다.

## 내용과 근거

가이드 본문은 개념, 설계 판단, 대안, 확인 방법과 적용 과제를 설명한다. PDF 판본이나 검토 범위를 수업 내용처럼 앞세우지 않는다. 사용자에게 책 카탈로그를 별도의 학습 단계로 제공하지 않으며, 경력·수준에 따라 콘텐츠를 나누거나 접근을 제한하지 않는다.

`sourceRefs`와 `design-sources.ts`의 서지·페이지·검토 한계는 내부 근거로 보존한다. 확인 가능한 출처와 제작 설명은 학습 콘텐츠 맨 아래의 작은 `출처·제작 정보` details에 기본으로 닫아 둔다. 출처 표시를 줄인다는 이유로 읽지 않은 범위까지 검토했다고 쓰거나 사례를 실제 연구 결과로 바꾸지 않는다.

기존 제품·포트폴리오 등 확인된 사례 링크는 `실제 사례 더 보기`로 보존한다. 원본 PDF, 페이지 이미지, 비공개 Drive 링크를 학습 화면에 복제하지 않는다. 자료별 이전 검토 근거는 `pdf-editorial-review.md`에 남기되 그 문서의 과거 화면 구성과 검사 결과를 현재 결과로 간주하지 않는다.

## 검증 기록

2026-10-31 통합 변경 검증:

- TypeScript 검사, 변경한 TypeScript 파일의 ESLint 검사, production build 통과.
- 전체 테스트 13개 파일·101개 통과. 239개 용어의 내용·연결, 20개 가이드 본문과 출처, 메뉴 및 기존 주소 이동, 검색·필터·페이지·포커스 유지 검증을 포함한다.
- 실제 컴포넌트를 사용한 로컬 검수 화면에서 데스크톱과 390px 모바일 배치를 확인했다. 모바일에서 펼친 20개 가이드에 수평 넘침이 없음을 확인했다.
- 관련 용어를 같은 모달에서 열고 닫아 기존 검색·주제 필터로 복귀하는 흐름, 접힌 가이드 열기와 검색, `/materials`의 `/glossary` 이동을 브라우저에서 확인했다.
- PDF 출처 관계와 페이지 정보는 유지했고, 원본 PDF를 학생에게 배포하는 기능은 추가하지 않았다. 인증 경계와 수업 일정은 변경하지 않았다.

운영 반영 여부는 이 문서의 사전 검사 기록과 구분하며, 이 변경의 GitHub 병합 커밋과 Vercel production 배포 상태로 확인한다.
