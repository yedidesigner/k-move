# K-Move 커리큘럼 Google Sheet 연결

이 연결은 **LMS에서 저장한 수업 초안 → 원본 Google Sheet의 시트2** 방향으로 동작합니다. 학생에게 수업을 공개하는 기능은 별도입니다. Sheet를 직접 수정한 내용은 LMS로 가져오지 않으며, 동일 셀의 외부 수정을 발견하면 자동 덮어쓰기를 중단합니다.

코드 배포만으로 Google 계정 연결이 완료되지는 않습니다. 원본 문서 편집 권한이 있는 강사가 처음 한 번 Apps Script 설치 함수를 실행하고 Google 권한을 승인해야 합니다. 웹 앱 배포, 서비스 계정 키, Google OAuth 클라이언트 생성, 강사 로그인 비밀번호 입력은 필요하지 않습니다.

## 고정된 연결 대상

- 원본 문서: <https://docs.google.com/spreadsheets/d/1Hv7dvSg_R98DM8_VlCCg7ckYRoopmSFlAQ8z_g5Cds0/edit#gid=2001>
- 대상 탭: 이름과 관계없이 `gid=2001`인 시트2
- 대상 수업: `S01`–`S24`. A열이 `회차` 또는 `주차`인 고유한 표 헤더를 찾고, B열의 `구분(사이클)`을 우선 확인합니다. 그 헤더 아래에서만 `1회차`–`24회차` 또는 `1주차`–`24주차`를 찾아 대응합니다. 헤더 위 개요 영역의 같은 표시는 무시합니다.
- A열과 다른 탭은 수정하지 않습니다. 행 번호를 고정하지 않으며, 같은 회차가 두 번 나오면 해당 수업의 반영을 중단합니다.
- 원본을 복사한 문서는 ID가 다르므로 이 스크립트가 동작하지 않습니다.

| Sheet 열 | LMS에서 반영하는 값 |
| --- | --- |
| B | 커리큘럼 사이클 |
| C | 수업 제목, 빈 줄, 목표·산출물 |
| D | 핵심 학습 내용 — 항목마다 줄바꿈 |
| E | 주요 용어 — `용어: 설명` 형식 |
| F | 사용 도구 — 쉼표로 구분 |
| G | 과제 |
| H | 수업 날짜 (`YYYY-MM-DD`) |
| I | 시작 시간 (`HH:mm`) |
| J | 종료 시간 (`HH:mm`) |

강사 메모, 학생 정보, 학생 제출물, 피드백, LMS 계정 정보는 내보내지 않습니다. 상세 본문과 연결 학습자료처럼 위 표에 없는 LMS 필드도 Sheet로 내보내지 않습니다. 최초 기준 셀은 운영자가 원본 확인 후 서버에 등록하며, 스크립트가 임의로 최초 내용을 덮어쓰거나 기준으로 채택하지 않습니다.

## 최초 설치

원본 시트의 [연결 스크립트](https://script.google.com/u/0/home/projects/18mIIMLdimS1m3ApX-pHNMtVpgU4V0Z0KuayLLp9IufGtpg8St4_pgCXA/edit)에 아래 소스와 매니페스트를 저장하고 내용 일치까지 확인했습니다. 현재 남은 단계는 강사의 Google 승인과 일회용 코드 연결입니다. 이미 준비된 프로젝트를 사용하는 경우 3~4번의 코드 복사 과정은 생략합니다.

1. LMS에 강사 계정으로 로그인하고 **강사 설정 → Google Sheet 자동 반영**을 엽니다.
2. 원본 문서를 열고 **확장 프로그램 → Apps Script**로 이동합니다. 독립형 스크립트를 새로 만들면 안 됩니다.
3. [`kmove-curriculum-sync.gs`](../public/integrations/kmove-curriculum-sync.gs)의 내용을 새 `.gs` 파일에 넣습니다. 운영 주소에서는 `/integrations/kmove-curriculum-sync.gs`로 받을 수 있습니다. 이미 프로젝트에 코드가 있다면 보존합니다. 메뉴는 별도 `kmoveOpenMenu` 트리거로 설치하므로 기존 `onOpen` 함수를 바꿀 필요가 없습니다.
4. Apps Script **프로젝트 설정 → 편집기에 appsscript.json 매니페스트 파일 표시**를 켭니다. [`appsscript.json`](../public/integrations/appsscript.json)의 권한과 V8 런타임을 적용합니다. 기존 프로젝트에 다른 기능이 있다면 기존 매니페스트를 무작정 덮어쓰지 말고 필요한 설정을 확인합니다.
5. LMS에서 **연결 코드 발급**을 누릅니다. 코드는 15분 동안 한 번만 사용할 수 있습니다. 코드와 개인 연결 키를 문서 셀이나 코드에 적지 않습니다.
6. Apps Script 함수 선택기에서 **`kmoveInstall`**을 선택하고 실행합니다. 원본 문서에 편집 권한이 있는 Google 계정을 선택하여 필요한 권한을 확인·승인합니다. 학교·회사 관리자가 차단한 경우에는 관리자에게 허용을 요청해야 하며 우회하지 않습니다.
7. 설치 창이 표시되면 LMS의 일회용 코드를 붙여 넣습니다. 스크립트는 이 계정의 연결 키를 생성하고 약 1분 간격의 트리거를 설치합니다.
8. LMS에서 연결 상태와 각 회차의 **반영 완료**를 확인합니다. 처음 설치된 상태와 실제 내용 반영 성공은 별도입니다.

Google 승인이 끝나도 설치 창이 나타나지 않으면 `kmoveInstall`을 다시 실행합니다. 코드가 만료되었거나 이미 사용되었다면 새 코드를 발급합니다. Google 동의 화면에서 요청되는 권한은 다음 세 가지입니다.

| 권한 | 목적 |
| --- | --- |
| `spreadsheets.currentonly` | 이 스크립트가 연결된 원본 문서만 읽고 수정 |
| `script.external_request` | 고정된 K-Move Supabase 서버에 변경 목록과 처리 결과 전달 |
| `script.scriptapp` | 설치한 계정으로 시간 트리거 생성·관리 |

`@OnlyCurrentDoc`와 명시적인 매니페스트를 함께 사용합니다. Google 토큰을 추출하거나 LMS에 전달하지 않습니다. 소스의 Supabase `publishableKey`는 공개 API 게이트웨이 키이며 강사 권한이나 비밀 서버 키가 아닙니다. 별도로 생성되는 연결 키는 Apps Script의 해당 사용자 `UserProperties`에만 저장하며 서버는 그 해시만 보관합니다.

## 일상 사용과 상태

- 강사가 LMS 수업을 수정하고 **초안 저장**을 하면 변경 대기열이 같은 DB 트랜잭션에 기록됩니다. 학생 공개 여부와 관계없이 Sheet 반영을 준비합니다.
- 시간 트리거는 약 1분 간격으로 실행합니다. Google 서비스 상황과 할당량에 따라 지연될 수 있으므로 실시간 반영이나 정확히 60초 이내 반영을 보장하지 않습니다.
- 문서를 새로 열면 **K-Move 연결** 메뉴가 나타납니다. **지금 반영하기**(`kmoveSyncNow`)로 즉시 확인하거나 **연결 상태**(`kmoveShowStatus`)로 마지막 실행 결과를 확인할 수 있습니다.
- **충돌**은 Sheet의 내용이 마지막 기준과 달라졌다는 뜻입니다. 변경을 검토한 뒤 LMS의 명시적인 덮어쓰기 동작으로 해결합니다. 스크립트는 기준을 자동 갱신하지 않습니다.
- 통신 장애는 1·2·4·8·16·30분으로 간격을 늘려 재시도합니다. 강제 즉시 실행은 대기 시간을 건너뜁니다. 사용자에게 원격 응답 원문, 연결 키, 수업 내용이 오류 로그로 노출되지 않게 합니다.
- 수식이 있는 관리 셀은 덮어쓰지 않습니다. 해당 셀은 원본과 운영 의도를 확인한 후 처리합니다. 강사가 입력한 `=`로 시작하는 텍스트는 수식으로 실행하지 않고 그대로 저장합니다.

## 연결 해제와 재연결

1. LMS에서 **자동 반영 연결 해제**를 누르면 서버가 기존 연결 키를 폐기합니다. 저장된 LMS·Sheet 내용은 삭제하지 않습니다.
2. 원본 문서의 **K-Move 연결 → 이 계정의 자동 연결 해제** 또는 Apps Script의 `kmoveUninstall`을 실행하면 이 Google 계정의 시간 트리거와 로컬 연결 키를 지웁니다. 다른 계정이 만든 트리거는 삭제하지 않습니다.
3. 다시 연결할 때는 LMS에서 새 코드를 발급하고 `kmoveInstall`을 실행합니다. Google 권한을 이전에 승인했다면 추가 승인이 표시되지 않을 수 있습니다.

트리거는 설치한 Google 계정으로 실행됩니다. 강사가 바뀌면 기존 연결을 해제하고 새 담당자가 설치해야 합니다. 문서 편집자는 연결된 스크립트 코드도 바꿀 수 있으므로 원본 문서의 편집 권한은 운영 담당자에게만 부여합니다. 이 문서의 수업 내용을 볼 수 있다는 이유만으로 학생에게 편집 권한을 줄 필요는 없습니다.

## 구현 및 검증 범위

- 서버는 저장 버전과 기준 셀을 유지하고, 한 수업의 미확정 버전을 새 버전이 추월하지 못하게 합니다. 만료된 작업은 같은 스냅샷으로 재시도합니다.
- 작업은 한 번에 최대 4개로 제한하고, 작업 사이에 약 45초의 실행 예산을 확인하여 다음 작업 시작을 중단합니다. 이미 실행 중인 Google API·네트워크 호출을 강제로 종료하는 시간 제한은 아니며 Google 실행 제한이 적용됩니다. HTTP 리다이렉트를 따라가지 않습니다.
- 작업 전 원본 문서·탭, 수업 ID, 데이터 형식, 임대 권한을 확인합니다. 셀과 회차 위치를 다시 읽고, 일반 텍스트로 쓰고, 다시 읽어 동일한지 확인한 뒤 완료 처리합니다.
- ACK 응답이 유실되어도 다음 실행에서 이미 원하는 내용이면 다시 쓰지 않고 완료만 확인합니다.
- `LockService`는 이 스크립트의 중복 실행을 막습니다. 사람의 동시 편집을 잠그지는 않습니다. Google Sheets에는 이 흐름에서 사용할 원자적인 셀 비교·쓰기 기능이 없으므로 아주 짧은 동시 편집 구간까지 완전히 제거하는 것은 아닙니다. 변경 직전·직후 확인으로 일반적인 충돌을 감지합니다.
- 로컬 VM 테스트는 잘못된 대상, 중복 회차, 외부 편집, 수식, 취소된 작업, 읽기 검증 실패, ACK 유실 재시도와 재시도 간격을 검증합니다. 로컬 테스트가 Google 계정 설치 또는 운영 Sheet의 실제 반영 성공을 의미하지는 않습니다.

검증 명령: `npm test -- --run src/test/curriculum-sheet-worker.test.ts`

운영 연결 완료 검증은 권한 승인 후 강사가 수정한 한 수업의 저장 버전과 Sheet 셀 내용이 일치하고 **반영 완료**로 표시되는지 확인합니다. 검증을 위해 무관한 학생 데이터나 다른 탭을 수정하지 않습니다.

초기 반영 시 원본 시트2의 24회차 × 10열을 LMS 원본과 대조했습니다. 서버 마이그레이션 후 롤백 검증으로 강사·학생 권한, 임대 복구, 충돌 확인, 비공개 메모 제외를 검사했고, 24회차 기준 셀을 등록했습니다. `curriculum-sheet-sync-check.sql`은 초기 기준 등록 전에 실행하는 롤백 전용 점검이며, 운영 대기열을 삭제하지 않습니다.
