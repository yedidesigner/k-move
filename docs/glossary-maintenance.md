# K-Move 용어집 관리

## 기준 데이터

`src/data/glossary.json`이 LMS 용어 콘텐츠의 기준입니다. 이번 정리는 기존 239개 항목을 유지하며, 각 항목에 영어, 한국어 발음, 뜻, 정의, 활용 예시를 제공합니다.

- `id`: 변경하지 않는 고유 식별자. 새 항목은 중복되지 않는 영문 kebab-case ID를 사용합니다.
- `english`: 영어 표제어. 목록은 이 값으로 A–Z 자동 정렬합니다.
- `pronunciation`: 한국어 독음을 괄호 없이 입력합니다. 화면이 `[...]`를 붙입니다. 한글 독음은 학습을 돕기 위한 근사 표기이며 IPA가 아닙니다.
- `korean`: 짧은 한국어 뜻.
- `description`: 초보자가 이해할 수 있는 정확한 정의. 필요한 실무 주의사항은 `[실무 참고]` 뒤에 기록할 수 있습니다.
- `example`: 해당 개념이 드러나는 구체적인 디자인·리서치·업무 상황 한 문장.
- `letter`: 원본에 보관하는 첫 알파벳. LMS는 `english`의 첫 글자에서 다시 계산하므로 필터와 정렬이 일치합니다.
- `lessonId` (선택): 처음 제작한 세 전용 UI 실습을 연결합니다. 값은 `cta`, `hamburger`, `carousel`입니다. 그 외 실습은 아래의 별도 실습 데이터에서 같은 용어 ID로 연결합니다.

새 용어를 추가하면 전체 개수, A–Z 정렬, 검색 대상과 페이지 수가 데이터에서 계산됩니다. 첫 화면이나 필터 숫자를 따로 수정하지 않습니다. 기존 용어의 수정은 같은 `id`를 유지합니다.

## 카드와 실습

카드 본문은 설명·예시를 뒤집어 확인하는 버튼입니다. 모든 239개 카드의 하단 ‘핵심 구조 · 직접 해보기’ 버튼은 별도의 버튼으로 학습창을 엽니다. 버튼을 서로 중첩하지 않습니다.

`src/data/practice/entries.json`에 기존 세 전용 실습을 제외한 236개 용어별 실습을 저장합니다. 각 실습은 `src/data/practice/types.ts`의 타입을 따릅니다. `glossary-practice.ts`가 용어 ID와 실습을 연결하며, 실제 콘텐츠가 없는 항목에 가짜 실습 버튼을 표시하지 않습니다.

실습 유형은 다음과 같습니다.

1. `visual`: 화면 조작과 비교. 간격·크기·대비·레이아웃·내비게이션 등 실제 화면 상태를 바꿉니다.
2. `decision`: 구체적인 상황에서 행동을 선택하고 각 선택의 결과와 이유를 확인합니다.
3. `sort`: 항목을 분류하고 항목별 피드백을 확인합니다.
4. `sequence`: 해당 연습 상황에 맞게 단계를 재배열하고 단계 간 관계를 확인합니다. 모든 업무에 적용되는 고정 절차를 의미하지 않습니다.

모든 실습에 상황, 지시문, 핵심 관계 도식, 기억할 점을 작성합니다. 도식은 원본 HTML/SVG로 표현하며 flow만 순서와 방향을 갖습니다. compare/group을 절차로 표현하지 않습니다. 시각 실습의 16개 preset에는 해당 속성을 보여 주는 원본 SVG 핵심 구조 그림이 있습니다. 그림의 접근 가능한 이름과 설명도 함께 작성합니다. 시각 실습의 지시와 비교 설명은 해당 preset의 실제 조작 항목 및 상태와 일치해야 합니다. 새 용어 추가 시 정의 데이터와 실습 데이터를 함께 추가하고 전체 연결 검사를 통과시킵니다.

정답 선택지만 반복해서 첫 번째에 놓지 않습니다. 오답에도 용어와 상황에 맞는 구체적인 이유를 제공하고, 분류·순서 실습은 다시 시도할 수 있게 합니다. 자유 입력에 대해 의미를 자동 판정하지 않으며, 화면 내부 예시는 실제 가입·저장·전송을 하지 않습니다.

완성한 뒤 실제 클릭 결과, 키보드 조작, 모바일, 초기화, 닫기·포커스 복귀를 확인합니다. 유형별 개수와 전체 실습 수는 데이터에서 계산합니다.

CTA의 목록 표시는 `CTA`이며 원래 영어 표제어 `Call-to-action (CTA)`도 검색할 수 있습니다. 기존 세 실습은 가상의 교육용 UI이며 실제 가입·결제·강의 신청을 하지 않습니다.

## Figma

파일: https://www.figma.com/design/XF0sIQq6KmdbIynyXUWmsD

Figma의 통합 목록과 A–Z 카드 카탈로그는 동일한 용어 데이터를 기반으로 만든 편집 가능한 디자인 자료입니다. 앞면과 설명면은 같은 용어의 두 상태이며 서로 다른 용어로 세지 않습니다. 향후 추가 시 알파벳 그룹 안의 영어 순서를 유지하고 재사용 카드 컴포넌트의 인스턴스를 사용합니다.

LMS 데이터 변경이 Figma에 자동으로 동기화되지는 않습니다. 다음 콘텐츠 추가 작업에서 JSON과 Figma를 함께 갱신하고 개수·ID·정렬을 다시 대조합니다. 기존 세 학습 화면의 프로토타입과 신규 카탈로그의 실제 연결 상태는 구분해 확인합니다.

## 콘텐츠 검수와 배포

- 전체 항목의 고유 ID와 필수 필드 누락을 확인합니다.
- 정의에 기능·역할·형태를 혼동한 내용이나 근거 없는 절대 규칙이 없는지 확인합니다.
- 발음과 뜻을 검토하고 예시가 정의를 정확하게 보여 주는지 확인합니다.
- 용어 개수가 늘면 현재 239개를 검증하는 기준 테스트도 승인된 새 항목 수·목록으로 갱신합니다.
- 검색/필터 조합, 페이지 이동, 긴 설명, 작은 화면, 기존 실습을 검사합니다.
- `npm test`, TypeScript 검사, `npm run build` 후 기존 Vercel 프로젝트로 배포합니다.

용어 목록의 기존 출처는 LMS 하단의 원본문서 링크에 남깁니다. 이번에 작성한 활용 예시는 교육용 가상 상황입니다. 외부 스크린샷을 최종 학습 UI로 복제하지 않습니다.
