# K-Move 용어집 관리

## 기준 데이터

`src/data/glossary.json`이 LMS 용어 콘텐츠의 기준입니다. 이번 정리는 기존 239개 항목을 유지하며, 각 항목에 영어, 한국어 발음, 뜻, 정의, 활용 예시를 제공합니다.

- `id`: 변경하지 않는 고유 식별자. 새 항목은 중복되지 않는 영문 kebab-case ID를 사용합니다.
- `english`: 영어 표제어. 목록은 이 값으로 A–Z 자동 정렬합니다.
- `pronunciation`: 한국어 독음을 괄호 없이 입력합니다. 화면이 `[...]`를 붙입니다. 한글 독음은 학습을 돕기 위한 근사 표기이며 IPA가 아닙니다.
- `korean`: 짧은 한국어 뜻.
- `description`: 초보자가 이해할 수 있는 정확한 정의. 필요한 실무 주의사항은 `[실무 참고]` 뒤에 기록할 수 있습니다.
- `example`: 해당 개념이 드러나는 구체적인 디자인·리서치·업무 상황 한 문장.
- `letter`: 원본에 보관하는 첫 알파벳. LMS는 `english`의 첫 글자에서 다시 계산하므로 필터와 정렬이 일치합니다.
- `lessonId` (선택): 처음 제작한 세 전용 UI 실습을 연결합니다. 값은 `cta`, `hamburger`, `carousel`입니다. 그 외 실습은 아래의 별도 실습 데이터에서 같은 용어 ID로 연결합니다.

새 용어를 추가하면 전체 개수, A–Z 정렬, 검색 대상과 페이지 수가 데이터에서 계산됩니다. 첫 화면이나 필터 숫자를 따로 수정하지 않습니다. 기존 용어의 수정은 같은 `id`를 유지합니다.

## 학습 방식: 예시 또는 예시 + 실습

카드 본문은 설명·예시를 뒤집어 확인하는 버튼이고 뒷면은 흰 배경·검정 텍스트입니다. 하단의 별도 학습 버튼으로 시각 예시를 엽니다. 두 버튼을 중첩하지 않습니다.

`src/data/learning/entries.json`이 239개 학습 방식과 시각 자료의 기준입니다. `glossary-learning.ts`가 용어 ID로 연결합니다. 현재 `example` 195개, `practice` 44개입니다. 목록과 필터 숫자는 이 데이터에서 계산합니다.

- `example`: 시각 예시 → 관찰 포인트 → 참고 자료(있는 경우) → 기억할 점. 산출물·직무·연구 개념 등에 사용하며 퀴즈와 가짜 조작을 표시하지 않습니다.
- `practice`: 위 시각 자료 다음에 실제 조작이 개념 이해에 도움이 될 때만 직접 해보기를 표시합니다. 간격·레이아웃·반응형·글자 조절, 실제 정보/메모 분류 등이 해당합니다.
- `rationale`: 편집자용 학습 방식 선택 이유이며 학습 화면에 노출하지 않습니다.
- `figure`: 용어에 맞는 원본 시각 자료와 짧은 해설입니다. 결과물은 case-study/persona/journey-map 등 실제 형태로, 원리는 필요한 정확한 SVG로 표현합니다. 단순 텍스트 카드나 장식 도형만으로 다른 개념을 같은 그림처럼 표현하지 않습니다.
- `references`: 확인한 원문 URL, 제목, 관찰할 점. 실제 제품·수업 프로젝트·가상 예시를 구분합니다. 외부 화면을 무단 복제하지 않습니다.
- `practiceReason`: 조작이 실제로 무엇을 학습하게 하는지 설명합니다. 실습 모드에서 필수입니다.

새 용어는 먼저 가장 적합한 시각 예시를 작성합니다. 모든 용어에 실습을 강제하지 않습니다. 실습이 정의와 직접 연결되고 실제 UI 상태 변화를 보여 줄 때만 `practice`를 선택합니다. 생성형 이미지는 정확한 구조 도식의 대안으로 사용하지 않습니다.

`src/data/practice/entries.json`은 이전 236개 활동 데이터를 보관합니다. 현재 공개 여부는 오직 learning mode로 결정합니다. `example` 항목에 이전 활동 데이터가 있어도 실습을 렌더링하지 않습니다. `getGlossaryPractice`는 기억할 점을 재사용하기 위해 원본 활동을 반환할 수 있으므로 노출 판단에는 `getLearningMode`/`hasGlossaryPractice`를 사용합니다.

기존 CTA·햄버거 메뉴·캐러셀은 `lessonId`로 연결하는 전용 데모를 사용합니다. CTA 목록 표시는 `CTA`이며 원래 영어 표제어 `Call-to-action (CTA)`도 검색할 수 있습니다. 화면 내부 예시는 실제 가입·저장·전송을 하지 않습니다.

실습의 시나리오·지시·비교 라벨은 실제 엔진 컨트롤과 일치해야 합니다. 정적 그림을 인터랙티브라고 설명하거나 예제 하나의 조작을 전체 접근성 평가 등으로 확대하지 않습니다. 사용자 입력은 의미를 자동 판정하지 않습니다. 검수에서 실제 클릭 결과·키보드·모바일·초기화·모달 닫기와 포커스 복귀를 확인합니다.

## Figma

파일: https://www.figma.com/design/XF0sIQq6KmdbIynyXUWmsD

Figma의 통합 목록과 A–Z 카드 카탈로그는 동일한 용어 데이터를 기반으로 만든 편집 가능한 디자인 자료입니다. 앞면과 설명면은 같은 용어의 두 상태이며 서로 다른 용어로 세지 않습니다. 향후 추가 시 알파벳 그룹 안의 영어 순서를 유지하고 재사용 카드 컴포넌트의 인스턴스를 사용합니다.

LMS 데이터 변경이 Figma에 자동으로 동기화되지는 않습니다. 다음 콘텐츠 추가 작업에서 JSON과 Figma를 함께 갱신하고 개수·ID·정렬을 다시 대조합니다. 기존 세 학습 화면의 프로토타입과 신규 카탈로그의 실제 연결 상태는 구분해 확인합니다.

## 콘텐츠 검수와 배포

- 전체 항목의 고유 ID와 필수 필드 누락을 확인합니다.
- 정의에 기능·역할·형태를 혼동한 내용이나 근거 없는 절대 규칙이 없는지 확인합니다.
- 발음과 뜻을 검토하고 예시가 정의를 정확하게 보여 주는지 확인합니다.
- 용어 개수가 늘면 현재 239개를 검증하는 기준 테스트도 승인된 새 항목 수·목록으로 갱신합니다.
- 검색/필터 조합, 페이지 이동, 긴 설명, 작은 화면, 기존 실습을 검사합니다.
- `npm test`, TypeScript 검사, `npm run build` 후 기존 Vercel 프로젝트로 배포합니다.

용어 목록의 기존 출처는 LMS 하단의 원본문서 링크에 남깁니다. 이번에 작성한 활용 예시는 교육용 가상 상황입니다. 외부 스크린샷을 최종 학습 UI로 복제하지 않습니다.
