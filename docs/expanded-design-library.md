# 디자인 용어집과 주제별 학습자료 확장

2026-11-01 (한국시간). 이번 요구는 이전 통합 메뉴 결정을 갱신한다. 학습 대상은 계속 ‘디자이너’ 하나이며 용어집과 학습자료는 서로 다른 학습 과업을 담당한다.

## 학습 범위

기존 239개 표제어·한국어 정의·PDF 기반 실무 해설을 보존하고 120개를 추가해 359개로 확장한다. 기존 20개 가이드에 8개를 보강해 총 28개를 제공한다. 이 숫자는 디자인의 모든 분야를 완전히 망라한다는 뜻이 아니다. 기존 UX·UI 중심 목록의 누락을 타이포그래피/조형·색상, 그래픽/인쇄·브랜딩, UI 패턴/상태, 리서치/콘텐츠의 네 분야에서 보완했다.

각 용어에는 영어·한국어·발음·검색 별칭, 정의와 구체적 예시, 관찰 포인트, 적용 상황과 선택, 트레이드오프와 확인 방법, 혼동 개념, 근거를 둔다. 새 용어의 출처는 직접 확인한 공식·저자 자료를 기록하며 제공 PDF의 근거인 것처럼 페이지를 만들지 않는다. 기존 PDF 10종의 실제 확인 페이지와 한계 표시는 그대로 보존한다.

신규 120개 용어 모두 핵심 구조 도식과 맥락 예시를 각각 직접 작성한 HTML/CSS/SVG로 구성한다. 타이포그래피 해부, 인쇄 경계·분판, UI의 상태, 연구 산출물 등을 실제 맥락에서 구분할 수 있게 만든다. 가상 수치와 정적 도식은 그렇게 표시하며, 실제 ICC 변환이나 연구 결과·제품 동작으로 오인시키지 않는다. 기존 실제 사례 링크와 CTA·햄버거 메뉴·캐러셀 실습은 유지한다. 새 UI 용어 중 직접 선택 결과를 비교하는 것이 유용한 6개에는 실제 작동하는 실습을 제공한다.

## 화면 위계

- 용어집은 검색·주제 선택을 우선 제공하고, 학습 유형/A–Z는 ‘상세 필터’ 안에 둔다. 12개 카드 단위로 탐색한다.
- 카드의 영어 용어와 발음/한국어 뜻을 우선하고, 뒤집은 면은 흰 바탕·검정 텍스트를 유지한다.
- 용어 상세는 ‘핵심 구조 → 예시·실습 → 실무 해설’ 중 한 패널만 보인다. 탭은 키보드 이동을 지원하고 이미 열었던 실습의 상태를 보존한다.
- 학습자료의 ‘주제별로 이어 배우기’에서 주제 또는 검색으로 가이드를 고른다. 한 번에 한 가이드만 열며 ‘개념 이해 / 설계 판단 / 내 작업에 적용’으로 읽을 범위를 나눈다.
- 가이드의 ‘내 작업에 적용’ 하단에서는 같은 주제의 다음 가이드 한 개로 연결한다. 마지막 가이드에는 없는 다음 단계나 완료 기록을 만들지 않는다.
- 모바일 상단의 보조 링크는 기본 닫힌 ‘추가 메뉴’에 둔다.
- 경력·준비생·프로 분류는 없다. PDF 책 카탈로그나 원본 다운로드 대신, 각 콘텐츠 마지막의 기본 닫힌 출처 정보를 제공한다.

설계 참고: NN/g Progressive Disclosure(https://www.nngroup.com/articles/progressive-disclosure/)의 핵심/부가 정보 구분과 W3C Page Structure(https://www.w3.org/WAI/tutorials/page-structure/)의 제목·영역 관계를 적용했다. 이는 학습 효과가 검증된 실험 결과라는 주장이 아니라 이번 화면 구성의 근거다.

## 콘텐츠 유지

`src/data/expansion/manifest.json`이 새 ID를 관리하고 각 팩의 JSON이 설명과 출처를 보관한다. `expansion/index.ts`가 공통 목록으로 연결하며 기존 파일의 239개와 중복되지 않아야 한다. `expansion/guides.json`의 관련 ID와 `visualTermId`는 실제 용어와 일치해야 한다. 화면 예시는 `glossary/expanded`의 개별 컴포넌트에 연결한다. 후속 추가 시 출처가 없는 조작·수치를 새로 주장하지 않는다.

조사 범위와 개념상 주의점은 `research-visual-expansion.md`, `research-production-expansion.md`, `research-interaction-expansion.md`, `research-method-expansion.md`, `research-guide-expansion.md`에 기록한다.

## 검증

- 기존 239개 ID를 유지한 359개 용어, 신규 120개 핵심 도식·맥락 예시, 28개 가이드, 102개 추가 웹 출처 항목의 연결을 확인했다. 기존 WCAG의 약어/정식명 두 항목을 보존하므로 359개의 서로 다른 개념을 뜻하지는 않는다.
- 전체 테스트 14파일/108개 통과, TypeScript 검사 통과, 변경 TypeScript 파일 ESLint 오류·경고 0, production 빌드 통과. 빌드에는 기존 구조와 콘텐츠량에 따른 큰 청크 경고가 남아 있다.
- 데스크톱 브라우저에서 12개 카드, 닫힌 상세 필터, 검색, 3단계 용어 학습, 관련 용어 이동, 아코디언 동시 펼침, 탭 방향키, 기존 CTA 패널·햄버거 열기/닫기·캐러셀 이동 및 변형의 선택 보존을 확인했다.
- 학습자료의 주제 선택→단일 가이드→개념 전환/설계 판단/내 작업 적용→같은 주제 다음 가이드 흐름, URL 변경, 목록 필터·포커스 복귀를 확인했다. Back/Forward와 유효한 직접 가이드 주소는 라우터 통합 테스트로 검증했다.
- 320px iframe에서 신규 120개 맥락 예시의 문서 가로 넘침과 120개 핵심 도식의 누락·가로 넘침·SVG 글자 영역 잘림이 없음을 DOM으로 확인했다. 그림자·원형·컵 손잡이·툴팁처럼 의도된 내부 확장은 구분했다. 아코디언·도련·신뢰구간·커닝 대표 화면을 시각 검수했다. 390px에서 용어 모달과 학습자료 탐색의 가로 넘침이 없음을 확인했다.
- 브라우저 검수는 동일 컴포넌트를 사용하는 별도 로컬 QA 진입점에서 수행했다. 운영 인증을 우회하거나 변경하지 않았으며 실제 학습자 계정의 로그인 이후 전체 흐름을 검증했다는 뜻은 아니다.
- 최신 운영 커리큘럼 커밋 `74bc791fc3284377ec3e6d895d126fb410f4274a`를 fast-forward로 받아 보존한 뒤 전체 테스트·TypeScript·빌드를 다시 통과했다. 수업 내용·날짜·ID와 인증/DB 정책은 이번 변경 대상이 아니다.

운영 반영은 해당 GitHub 병합 커밋과 Vercel production 배포 상태를 별도로 확인한다.
