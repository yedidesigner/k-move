## 정확성 검토

- RGB와 색 공간을 구분하고 CMYK 값의 출력 의존성을 명시했다. 색역을 단순한 RGB가 CMYK 전체를 포함하는 그림으로 그리지 않았다.
- Soft proof 예시는 실제 ICC 변환이 아닌 관계 설명임을 명시했다. 색상·도트의 화면 그림을 측정 결과나 실제 인쇄 견본으로 제시하지 않는다.
- Overprint와 knockout의 아래 분판 유지·제거를 구별했다. Trapping의 작은 겹침은 이해를 위해 확대했으며 폭을 보편 규칙으로 적지 않았다.
- Bleed·trim·safe area·crop marks를 같은 구조에서 서로 다른 경계로 보여준다. 3mm를 보편 규격으로 쓰지 않고 제작처의 지침을 따르게 했다. MOO의 실제 지침에서는 자동 crop marks 처리를 확인했다.
- 2400px / 8in = 300ppi, 2400px / 16in = 150ppi로 계산했다. DPI와 PPI의 일대일 대응을 주장하지 않는다.
- Vector 형식에도 raster가 포함될 수 있음을 설명했다. Bézier의 핸들이 곡선 위에 있어야 한다고 가르치지 않는다.
- Photoshop의 alpha 선택 채널과 실제 파일 투명도를 구별했다.
- 실제 브랜드 지침은 개념 분석용이며 화면의 MORAE 브랜드·구도·그림은 원본 교육 예시이다. 실제 로고·사진을 복제하지 않는다.
- Source별 정의 근거만 간결하게 재서술했다. 작업 상황·의사결정·검수 예시는 K-Move의 독자적 교육 편집이며 출처의 연구 성과로 주장하지 않는다.
