## 편집 결과

- 용어별 정의, 식별 기준, 학습용 실무 상황과 설계 판단, 트레이드오프와 확인 근거, 헷갈리는 용어 비교를 작성했다.
- 8개 주제로 통합 용어집을 필터링한다. 원어·통용 한국어·독음·기존 검색 별칭을 보존한다.
- 기존 7개 가이드를 20개로 재편했다. 준비생·경력·프로 디자이너의 3개 학습 경로와 3개 학습 수준을 제공한다.
- 학습 자료의 내부 메뉴는 학습 가이드·학습 경로·참고 자료다. 사용자 역할과 관계없이 모든 가이드에 접근할 수 있다.
- 각 가이드에 학습 목표, 개념 설명, 가상 설계 사례의 선택·이유·대안·검증, 적용 과제와 결과물 점검 기준, 흔한 오해를 담았다. 제출·채점·완료 추적 기능으로 표현하지 않는다.
- 모든 PDF는 적어도 하나의 가이드에서 본문 근거로 사용했다. 일부 책은 관련 장만 검토했으며 전권 검토로 표시하지 않는다.
- 기존 239개 맥락 예시, 예시만 195개/실습 포함44개, CTA·햄버거·캐러셀 전용 데모, 흰색 카드 설명면을 유지한다.

## 근거와 편집 해설 구분

`concept`은 실제 본문이 직접 설명하는 개념, `application`은 설계 적용 참고, `context`는 관련 맥락이다. 개별 문헌이 해당 용어의 완전한 정의를 입증하지 않는 경우 관계를 보수적으로 표시했다. 직접 근거를 찾지 못한 항목에는 빈 출처 목록과 구체적인 `sourceNote`를 남겼다. 실무 사례·트레이드오프·검증 질문은 K-Move의 교육용 재구성이다.

전문 용어는 통용 명칭을 유지했다. 독립 검수에서 다음 경계를 확인하고 수정했다.

- CTA의 행동 역할과 버튼 외형, 무료 체험과 실제 결제 조건
- 햄버거 트리거와 펼쳐진 내비게이션, 캐러셀과 선택적 컨트롤
- 피델리티 차원과 와이어프레임·목업·프로토타입의 목적
- Initial focus의 시각적 초기 주목과 키보드 포커스·탐색 순서
- 정보구조 모델과 시각적 위계, 판단 편향과 기억 효과
- SUS 점수와 성공률, 참가자의 회상과 재현 과업의 관찰
- AI가 설명한 결과와 실제 저장·조회·오류 처리가 확인된 상태
- 이름을 지운 자료와 완전한 익명성, 현행 법률·계약 효력을 단정하는 설명

## 구현 범위

기준 정의는 `glossary.json`, 심화 해설은 `editorial/terms-1.json`부터 `terms-3.json`, 가이드는 `guides-foundation.json`, `guides-practice.json`, `guides-ai.json`이다. 이전 중복 가이드 파일은 제거했다. 자료와 경로는 타입 어댑터가 조합한다. 관련 용어는 ID로 현재 표제를 조회한다.

원본 PDF·책 페이지 이미지·추출 전문·비공개 Drive 링크를 배포하지 않는다. 공개 콘텐츠는 새로 작성한 한국어 설명, 기존 교육용 맥락 예시, 서지와 페이지 정보다. 인증·일정·백엔드·Figma 파일은 변경하지 않았다. 브라우저 검수용 인증 없는 화면은 별도 임시 하네스이며 운영 코드에 포함하지 않는다.

## 검증

- 239개 정의와 실무 해설 ID 완전 일치. 185개는 개념·적용·맥락 관계의 PDF 참조가 있고, 54개는 직접 근거 공백을 명시한 편집 해설이다. 참조가 있다는 사실을 모두 직접 정의 근거라는 뜻으로 사용하지 않는다.
- 20개 가이드에서 첨부10개 출처가 모두 사용되고 3개 경로가 전체 가이드를 연결한다.
- 전체 테스트 12개 파일96개 통과. 타입 검사와 변경 TS/TSX 파일 ESLint 통과. 프로덕션 빌드 성공.
- 실제 브라우저: 데스크톱 가이드 목록·학습 경로·모달, 모바일390px 가이드 필터·심화 가이드·참고 자료·용어 뒤집기·예시 모달·해설 펼치기를 확인했다. 별도 QA 하네스에서239개 열린 기본 해설의 가로 넘침0건을 확인했다.
- 기존 시각 예시와 새 정의의 주요 경계를 교차 검토했다. 모든 용어에 새 실습을 강제하거나 정적 예시를 인터랙션으로 바꾸지 않았다.
- 기존 대형 번들 경고는 남아 있다. 이번 작업은 콘텐츠·탐색 확장이며 새로운 성능 개선을 검증했다고 주장하지 않는다.
- 운영 배포는 테스트한 트리와 GitHub 커밋, Vercel production 연결을 대조하여 검증한다. 실제 배포 SHA와 상태는 배포 보고에 남긴다.
